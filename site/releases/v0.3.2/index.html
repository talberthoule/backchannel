Backchannel v0.3.2 bundles ffmpeg with the Windows and Linux desktop builds, so recording your voice profile, running a mic benchmark, and importing compressed audio need no extra installs -- and when audio conversion does fail, the error finally tells you why.

What changed

v0.3.2 removes the last external dependency from voice calibration and makes audio-conversion failures explain themselves.

Bundled ffmpeg

The Windows and Linux desktop builds ship a self-contained LGPL ffmpeg the app resolves automatically. Voice profile recording, mic benchmarks, and MP3, M4A, or WebM imports work with no separate install.

Errors that explain themselves

A missing ffmpeg now produces a clear "install FFmpeg and make sure it is on PATH" message, and decode failures surface ffmpeg's actual error instead of a raw system error code.

Clearer diarization status

The Diarization Capability card no longer shows a status tag that could read as "diarization is unavailable" when only the optional Enhanced mode was locked behind a benchmark.

Accurate provider setup

First-run setup now describes the Cloud AI path accurately: a Google or OpenAI key powers the analysis agents and live captions, while saved transcripts come from Gemini or the built-in local transcription models.

Resilient startup

Unrelated or legacy keys in a local .env file no longer fail settings validation at startup.

First-run notes

NeedWhat to do
Release access Use the email and password for your approved Backchannel recipient account.
Provider key Follow the guided setup on first launch, or add a key later in Admin -> API Keys. Calls will not start until the transcription model has a usable credential.
Voice calibration Works out of the box on Windows and Linux. On macOS, install ffmpeg and make sure it is on PATH before enrolling your voice.
Upgrading Quit the old version from the tray before starting the new one. Session data is stored per-user and shared by every version. The Admin About tab shows a what's-new notice after upgrading.
Desktop launch Backchannel opens a dedicated local app window in your default browser when it supports app windows, otherwise it uses a standard browser tab. It remains available from the system tray or menu bar.
Docker Check out the v0.3.2 source tag and rebuild Compose to run the same release through containers.

Start with the desktop app or self-host the stack

Both paths run Backchannel on your machine. Choose the desktop bundle for the fastest start, or Compose for maximum control.
