Release v0.3.4

Hotfix: Start Call works again.

Backchannel v0.3.4 repairs a bug shipped in v0.3.1 through v0.3.3 where pressing Start Call on a new session silently did nothing. Upgrading is strongly recommended for everyone on those versions.

What changed

v0.3.4 is a focused hotfix on top of v0.3.3. It contains the fix below and no other behavior changes.

Starting a call works again

In v0.3.1 through v0.3.3, pressing Start Call on a new session silently did nothing: the request that marks the session active hit a server error, so the call never began. The server error is fixed and starting a call works again for new and existing sessions.

No data was affected

Sessions created while the bug was present are intact and work normally after upgrading. Resuming completed sessions was never broken.

Covered by regression tests

The session state transitions that stamp call start and end times are now covered by an automated regression suite so this cannot silently break again.

First-run notes

NeedWhat to do
Release access Use the email and password for your approved Backchannel recipient account.
Provider key Follow the guided setup on first launch, or add a key later in Admin -> API Keys. Calls will not start until the transcription model has a usable credential.
Voice calibration Works out of the box on Windows and Linux. On macOS, install ffmpeg and make sure it is on PATH before enrolling your voice.
Upgrading Quit the old version from the tray before starting the new one. Session data is stored per-user and shared by every version. The Admin About tab shows a what's-new notice after upgrading.
Desktop launch Backchannel opens a dedicated local app window in your default browser when it supports app windows, otherwise it uses a standard browser tab. It remains available from the system tray or menu bar.
Docker Check out the v0.3.4 source tag and rebuild Compose to run the same release through containers.

Start with the desktop app or self-host the stack

Both paths run Backchannel on your machine. Choose the desktop bundle for the fastest start, or Compose for maximum control.
